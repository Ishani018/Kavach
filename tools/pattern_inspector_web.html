What is Kavach?

An AI-agent firewall that reads meaning, not strings.

When an AI agent decides to take an action — run a command, send an email, click a button — Kavach intercepts that decision and asks four specialised "ministers" whether the action looks dangerous. Each minister is a semantic detector: it embeds the proposed action and compares it against a curated corpus of attack patterns from MITRE ATT&CK, OWASP, CWE, and real agent CVEs.

This lab calls the real parliament backend — the same embedding model, the same ChromaDB corpus, the same run_minister_hybrid and Speaker the live server uses. Every number you see here is the number Kavach produces.
